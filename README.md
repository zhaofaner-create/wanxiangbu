# 万象簿

一个免登录、优先把数据存在你自己设备上的个人生活管理网页应用。今日计划、学习任务、饮食计划、库存管理、个人记账、游戏娱乐记录、读书笔记、课堂笔记——十个模块放在一个页面里，不需要注册账号。其中九个模块从打开到使用完全不联网；「课堂笔记」模块的录音转文字、多语言互译、AI 整理笔记这三步需要联网，具体联网范围见下面「数据与隐私」，不影响其它模块继续完全离线使用。

## 项目解决什么问题

日常想找一个"记今天要做什么、记学习任务、记账、记读书笔记"的小工具，市面上的同类 App 大多要注册账号、把数据传到别人的服务器上，或者功能杂糅了太多用不上的社交/云同步特性。万象簿只做一件事：把这几类个人记录放进一个页面，数据留在本机浏览器里，不注册、不依赖任何第三方账号体系，打开即用，关掉浏览器数据也还在；除了"课堂笔记"这一个用到录音转文字和 AI 功能的模块，其它模块不联网、不依赖任何第三方服务器。

## 主要功能

- **首页总览**：今日/本周/历史三个视图，一眼看到当前安排。
- **今日计划**：待办事项管理，支持日期/开始时间/预计用时/优先级/备注，内置计时器和进度条，前一天没做完的会自动滚动到今天。
- **学习任务**：作业/考试跟踪，支持列表和看板两种视图，学习目标计时并自动生成"今日学习报告"。
- **提醒事项**：简单的提醒清单。
- **饮食计划**：一周三餐安排，内置常用菜谱库，可以根据本周计划一键生成购物清单。
- **库存管理**：家用物品库存，购物清单勾选后自动更新库存，能看到消耗趋势。
- **个人记账**：多币种记账（人民币/欧元/美元/日元/英镑/港币），多账户，预算超支提醒，收支统计图表；汇率可以手动填写，也可以点一下按钮联网查询最新汇率（可选，不点就完全不联网）。
- **游戏娱乐**：游戏进度、评分、评价记录，游玩时长统计。
- **读书笔记**：书目管理 + 每本书的多条笔记，读完趋势统计。
- **课堂笔记**：录音+实时转录成文字（浏览器自带的语音识别，目前 Chrome/Edge 桌面浏览器支持最好），可以选好几种目标语言互译，也可以一键让 AI 把转录整理成带标题/列表/表格的结构化笔记；多语言互译支持 Google 翻译、Azure Translator、DeepL 三家专门的翻译服务（在"数据与设置"里选一家当前生效，随时可以切换），整理笔记用你自己在"数据与设置"填的 Claude API 密钥。如果录课前选好了要互译的语言、也配置好了翻译服务，录音过程中每隔几秒会自动把新说的这一小段翻译出来显示在"实时翻译"面板里，不用手动点按钮，适合三个小时的长课边讲边看译文；结束录音时也会自动补翻一次刚说完的最后几句。翻译页里随时可以手动点"翻译"补上还没翻完的部分，或者点"全部重新翻译"整段重新来一遍（比如换了一家翻译服务之后）。
- **个人信息与设置**：昵称、头像（支持相册照片上传+可拖动缩放的裁剪）、白天/夜间模式、字体大小、数据备份/恢复；"多语言互译服务"设置项给课堂笔记的多语言互译用（Google 翻译/Azure Translator/DeepL 三选一），"AI 服务密钥"设置项给课堂笔记的 AI 整理笔记用（Claude API 密钥），密钥都只存在本机，不填对应的密钥就用不了对应的功能（录音转文字本身不需要密钥）。
- 支持手机、平板、桌面浏览器的响应式布局；可以选择"服务器模式"打开以支持安装到桌面/主屏幕和离线缓存。

## 安装方法

不需要安装任何东西，也不需要 Node.js 或任何依赖，直接就能用：

1. 下载或克隆这个仓库到本地。
2. 双击打开 `index.html`，就是完整可用的 App（这是最简单、最推荐的方式，全程不联网）。

如果想要"安装到桌面/主屏幕、支持离线缓存"这类类似原生 App 的体验（可选，非必需）：

3. 确认电脑上装了 Node.js。
4. 双击 `启动万象簿(服务器模式).command`（Mac），或在终端里执行 `node serve.js`，会自动打开浏览器访问本地服务器。
5. 在浏览器里用"添加到主屏幕"/"安装应用"，之后可以像 App 一样打开。

> 想跑自动化测试（可选，面向开发者）：`npm test`（部分端到端测试需要额外安装 Playwright：`npm install --save-dev playwright && npx playwright install chromium`）。

## 使用方法

打开 App 后，左侧（手机上是顶部汉堡菜单）是各模块导航，点进任意模块直接添加/编辑记录，所有改动会自动保存在浏览器本地存储里，刷新页面、关闭浏览器再打开都不会丢失。想在另一台设备上继续使用同一份数据，去"数据与设置"页导出一份备份文件，在另一台设备的同一个页面里导入即可；这是目前跨设备同步数据的方式，App 本身不会把数据发送到任何服务器。

## 输入输出示例

以"今日计划"为例：

**输入**（新增一条计划）：

```
内容：complete 财务建模作业
日期：2026-09-20
开始时间：14:00
预计用时：90 分钟
优先级：高
```

**输出**（保存后展示在列表里）：

```
[高] complete 财务建模作业
14:00 · 预计90分钟 · 2026-09-20
```

以"个人记账"为例：

**输入**：记一笔支出，金额 25 欧元，分类"餐饮"，账户"日常账户"。

**输出**：账户余额相应扣减，月度"收支图表"里对应柱状图数字更新，若这个月"餐饮"分类超过设置的预算上限，会显示超支提示。

以"数据备份"为例：

**输入**：在"数据与设置"页点击"导出/分享备份"。

**输出**：生成一个带当前日期时间的 JSON 文件（例如 `万象簿备份-2026-09-18-14-30-05.json`）。手机上会优先弹出系统分享面板，可以直接传给另一台设备；电脑上则是普通下载。之后可以通过"导入恢复"读取回来。

## 数据与隐私

所有数据只存在你当前使用的浏览器本地（今日计划、记账、笔记这些用 `localStorage`；课堂笔记的录音音频用 `IndexedDB`），默认完全离线，不会自动上传到任何服务器，本仓库和发布的页面本身也不包含任何人的真实个人数据。

App 里有以下几处**可选**的联网功能，都不会把你的记账/笔记等本地数据顺带发出去，也都要你自己先配置好才会发生任何请求；除了"课堂笔记"模块，其它九个模块从打开到使用完全不联网。这几处联网点里，除了下面特别说明的"多语言互译"，都要你点一次对应按钮才会联网一次，不点按钮就不会发生任何请求：

- **个人记账 · 刷新实时汇率**：点击"刷新实时汇率"按钮时，会向公开汇率查询服务（[Frankfurter](https://frankfurter.dev/)）发一次请求，只传币种代码，不涉及你的任何记账数据；不点这个按钮就完全不联网。
- **课堂笔记 · 录音转文字**：用的是浏览器自带的语音识别（Web Speech API），点"开始录音"之后，浏览器会把录到的语音发给它自己的语音识别服务来转成文字——这是浏览器厂商的服务，不经过万象簿或 Anthropic；目前只有 Chrome / Edge 等 Chromium 内核的浏览器支持得比较好，Safari / iOS 支持有限甚至不支持，不支持时这个模块会提示、不影响其它模块。
- **课堂笔记 · AI 整理笔记**：把转录出来的**文字**（不是录音本身）发给 Anthropic 的 Claude API，用的是你自己在"数据与设置"填的 Claude API 密钥，直接从你的浏览器发出去，不经过万象簿自己的任何服务器。密钥要你自己去 Anthropic 官网申请，只保存在这台设备本地。不点"生成笔记"按钮，转录内容就不会发去整理笔记。
- **课堂笔记 · 多语言互译**：把转录出来的**文字**发给你在"数据与设置→多语言互译服务"里选中的那一家——Google 翻译（Google Cloud Translation API）、Azure Translator 或 DeepL，同样是直接从你的浏览器用你自己的密钥发出去，不经过万象簿自己的任何服务器。三家的密钥分开填、分开存，只保存在这台设备本地，切换用哪一家随时免费、不影响已经翻译好的内容。**这一项是例外**：如果创建课堂笔记时选了要互译的语言、并且已经配置好了当前使用的翻译服务，翻译不需要手动点按钮触发——录音过程中每隔几秒会自动把新说的这一小段发去翻译一次，结束录音时也会自动补翻最后几句；没选互译语言、或者没配置翻译服务的话，不会有任何翻译请求发生，转录内容也不会因为这个功能被发出去。

  以上两个功能的密钥都要你自己去对应服务商官网申请，只保存在这台设备本地，不会被公开、不会同步给别人；分享这个 App 给朋友，他要用这些功能得填他自己的密钥，不会用到你的，也不会花你的钱。
